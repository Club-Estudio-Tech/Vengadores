# 🛡️ Los Vengadores - Repositorio Central

Bienvenidos al repositorio oficial de nuestro club de estudio. 
Este es un espacio colaborativo multidisciplinario diseñado para documentar nuestro aprendizaje, alojar código y estructurar laboratorios prácticos.

## 🗂️ Organización del Repositorio

Cada disciplina tiene su propio directorio. Por favor, mantén tus aportes dentro de tu área correspondiente:

* **Ciberseguridad:** Scripts de Python para pentesting, capturas de red, reglas de detección y reportes de respuesta a incidentes.
* **Inteligencia Artificial:** Pruebas de modelos, mitigación de inyecciones de prompts y algoritmos.
* **Desarrollo Backend/Frontend:** Código fuente, patrones de diseño y ejercicios de backend.
* **Ciencia de datos:** Procesamiento de bases de datos, limpieza y visualizaciones.

## 🤝 ¿Cómo contribuir?

1. Navega a la carpeta de tu área.
2. Crea una subcarpeta con el formato `YYYY-MM_Nombre_del_Proyecto` (Ej: `2026-08_Analisis_Botnet`).
3. Sube tu código y asegúrate de incluir un pequeño `README.md` interno explicando cómo ejecutar tu entorno o máquina virtual.

## ⚖️ Código de Conducta
Mantenemos un espacio de aprendizaje seguro. Comenta tu código, explica tus procesos (útil para cuando presentemos los Show & Tell en Discord) y no subas binarios maliciosos vivos sin empaquetar de forma segura.
